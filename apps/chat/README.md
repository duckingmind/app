# 即刻对话

即刻对话是一个基于 Proxy App 平台模型和媒体服务的聊天与创作应用。用户可以在
同一段对话里切换文本对话、图片、视频、音乐生成和音色设计，并通过模型目录使用当前账户可用的能力。

## 功能

- 创建、切换和删除会话
- 从当前账户可用的模型中选择文本模型
- 流式显示回复，并可随时停止生成
- 对失败或中断的回复主动重试
- 复制回复内容
- 根据首条消息生成会话标题
- 刷新后从本地存储恢复当前账户的会话历史
- 按模型目录切换图片、视频、音乐生成和音色设计模式
- 根据模型声明展示图片尺寸、质量、数量、视频时长和画幅、音乐时长和格式等参数
- 对话、图片和视频支持从文件选择器、拖放和剪贴板添加图片；对话附件及视频参考作为可复用素材直传 COS，图片编辑输入只随一次 `/images/edits` multipart 请求发送；会话不保存图片字节或短期签名链接
- 持续查询异步媒体任务，并以平台资产 ID 恢复生成结果地址
- 在应用内通过“创作任务”托盘查看跨对话任务，继续查询、取消可取消任务、重新编辑失败任务并返回原对话

应用内的任务托盘面向创作过程，只展示用户需要的状态、结果和下一步操作。完整任务历史、
批量取消/删除、回收站、供应商信息、费用明细和失败诊断仍由 Portal 的媒体任务中心负责，
避免把运营排障信息混入创作界面。

会话历史与草稿保存在当前设备浏览器的本地存储中，并按平台账户隔离，不会在每次对话后写入平台 item。旧版本保存在 `storage.user` 中的会话和草稿会在首次启动时迁移到本地，并删除原有云端记录。文本、图片、视频、音乐和音色设计模型分别从平台的公开目录读取，媒体参数不在应用内推断或写死。图像、视频、音乐和音色设计
任务通过 Gateway 提交；任务执行期间可以停止本地查询，平台任务仍会在后台运行。

音色设计使用独立的提交、恢复和取消接口，包含音色描述和不超过 500 字的试听文案。成功后展示可复用的 `voice_id` 和试听音频；平台当前不提供 TTS 语音合成。

## 运行

首次在 `app` 目录运行 `npm ci` 并构建共享 SDK，再在 Chat 子应用目录执行：

```bash
cd app
npm --prefix proxy-app-sdk run build
cd apps/chat
npm run dev
```

`npm run dev` 会先完成平台开发授权与应用校验，再启动 Vite 和平台代理。只运行 `npm run dev:server` 可以预览界面，但模型请求需要完整的开发运行时。

## 构建和打包

```bash
npm run pack
```

打包会自动构建并校验应用。只构建前端资源可用 `npm run build`；完整构建可用 `npx proxy-app build`，随后可运行 `npm run validate` 单独校验。

打包文件默认写入 `app/apps/chat/dist/chat.zip`。上传 ZIP 到开发者控制台后，在宿主中
测试版本，确认权限和模型调用正常，再提交发布。

应用只在首次升级时读取并清理旧版 `storage.user` 会话数据。新版聊天记录与草稿保存在本地；文本、图片、视频、音乐和音色设计模型仍通过 `@ducking-mind/proxy-app-sdk` 访问平台公开 API。

## Agent 能力

应用同时声明了 `chat` Agent 命名空间，并在应用运行时注册：`read_conversations`、
`read_messages`、`list_models`、`create_conversation`、`send_message` 和
`stop_generation`。写操作要求 `expected_revision` 与 `idempotency_key`，避免 Agent
在会话变化或网络重试时重复发送消息。完整调用顺序和恢复策略见 `agent/guide.md`。
