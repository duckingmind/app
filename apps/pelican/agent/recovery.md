# 恢复与重试

`REVISION_CONFLICT` 表示画面已经发生变化，本次写入未执行。先用 `read_studio` 读取新状态，确认意图后以新 revision 和新幂等键提交新操作。

`IDEMPOTENCY_CONFLICT` 表示同一个幂等键被用于不同参数或不同能力。原操作重试必须恢复原参数；新的操作使用新的幂等键。`INVALID_ARGUMENT` 表示输入缺少必填字段、超出范围或包含未声明参数，未执行写入。

超时不能证明写入失败。先读状态，确认同一操作仍需重试时才用原键和原参数重试。页面内缓存最近 256 次完成的写入；页面重载或超过缓存范围后，不依靠旧幂等键确认操作是否完成。
