# 衣境设计室

衣境设计室是面向电商商品创作的图片工作台。它使用 Proxy App 平台提供的
图片和文本模型，把商品素材整理成商品套图、详情页内容、服饰试穿和风格
复刻结果，并集中保存每次创作的作品和检查报告。

## 功能

- **商品套图**：上传商品原图，选择销售平台、语言、比例和图片类型，生成
  主图及营销场景图。
- **详情页**：组合内容模块，统一视觉方向，生成可下载的详情长图。
- **服饰试穿**：选择或上传模特，指定场景和姿势，将服饰应用到模特图上。
- **AI 模特和场景**：根据文字描述生成虚构模特，或为商品推荐拍摄场景。
- **风格复刻**：提供风格参考图和可选商品替换图，控制复刻程度及单图要求。
- **作品管理**：查看历史批次、逐图方案、生成状态和质量检查；支持单图下载、
  ZIP 下载、继续查询和手动复检。

生成前应用会根据所选模型的输入数量、比例和尺寸能力校验请求。生成结果
会逐张检查商品或人物一致性、构图和明显缺陷；检查结果是辅助判断，重要
细节仍应由使用者核对。

## 素材要求

- 每批最多上传 6 张商品或服饰原图；单张支持 JPG、PNG、WebP，大小不超过
  10 MB。
- 图片边长至少 64 像素，总像素不超过 4,000 万。
- 模特参考最多 25 张，风格复刻最多 20 张参考图，并可另外提供最多 6 张
  替换商品图。
- 生成规格取决于所选模型的能力；应用会禁用不支持的比例或输入数量。

请求返回任务编号时，应用会继续查询任务，不会因为页面刷新而重复提交。
停止操作只阻止尚未提交的后续任务，已经受理的任务仍可能完成。仅在当前
页面存在的临时图片结果无法跨刷新恢复时，请及时下载；远程图片地址的有效期
由平台决定。

## 运行

在本仓库的 `app` 目录执行：

```bash
npm install
npm run sdk:build
npm run design:dev
```

首次连接或请求模型时，开发环境可能要求完成平台登录。只运行应用自己的
Vite 命令可以预览界面，但没有平台开发运行时，图片生成、文本规划和用户
存储不会工作。

## 测试、构建和打包

```bash
npm run design:test
npm run design:build
npm run design:validate
npm run design:pack
```

打包文件默认写入 `app/dist/design.zip`。上传 ZIP 到开发者控制台后，在宿主
中测试版本，检查图片模型、文本模型、权限和下载流程，再提交发布。

应用清单需要 `storage.user`、`model.images` 和 `model.responses`。应用通过
`@ducking-mind/proxy-app-sdk` 访问平台能力；用户数据按账户隔离保存，模型
服务凭据不会放入应用包。
