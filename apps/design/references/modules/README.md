## 观察到的工作流程

| 模块 | 输入与设置 | 输出 |
| --- | --- | --- |
| 商品套图 | 同一商品最多 6 张；电商平台、目标市场、语言、比例；卖点与要求，可用 AI 辅助；智能匹配或自定义套图；可选风格分析与商品上架文案 | 默认 7 张，白底 1 张、场景 2 张、卖点 2 张、其他 2 张；自定义合计 7–20 张；可附上架文案 |
| A+/详情页 | 商品原图；平台、市场、语言、版式；卖点要求；多选页面模块 | 按选中模块生成协调的商品详情图片，并展示长图组合 |
| 爆款图复刻 | 最多 20 张参考图；可选最多 3 张替换商品图；每张参考图可附要求；统一要求、类型、复刻程度、语言、比例 | 根据参考图逐张生成，可保留构图或参考整体风格 |

详情页默认勾选首屏主视觉、核心卖点图、使用场景图、多角度图、场景氛围图、商品细节图。其余选项包括品牌故事、尺寸/容量/尺码、效果对比、详细规格/参数、工艺、配件/赠品、系列、成分、售后服务和使用须知。原站显示 Amazon 标准与高级 A+ 尺寸以及常见比例；本应用需按当前 Proxy 模型能力选用尺寸。

复刻类型包括电商商品图、服饰电商图、营销海报、社媒图文、创意海报和其他。参考风格会调整色彩与细节，高度复刻更接近原参考的视觉结构。原站默认比例随类型变化：商品与服饰为 1:1，社媒为 3:4，海报为 9:16。

这些是可见的产品行为与配置，并不代表已获得原站专有模型或服务端机制。本应用以独立的任务规划、提示词和 Proxy 模型接口实现对应工作流程。
