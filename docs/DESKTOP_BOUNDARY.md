# 桌面端代码边界

本公开仓库只发布 CLI、SDK、示例应用和标记为公开的开发文档。桌面主应用、Electron 宿主、桌面运行时、发布工具、品牌资源和安装包属于内部专有组件，由私有仓库维护，不随公开仓库发布。

公开 checkout 不包含 `desktop/` 或 `proxy-app-desktop-runtime/`。公开 CLI 不提供桌面构建和发布命令；获授权的内部 checkout 使用私有维护工具和桌面源码完成这些流程，公开安装不会尝试加载或打包桌面组件。

为支持公开 CLI、SDK 和示例应用的互操作，仓库可以保留应用侧 Agent manifest、schema、能力包校验、状态数据格式，以及供应用页面调用私有宿主的客户端适配接口。这些内容只定义公开应用如何声明能力并调用宿主 API，不包含宿主进程、IPC 处理程序、工具发现与调用路由、授权执行、应用管理或更新发布实现；`desktop` target 名称也不代表宿主源码已开源。

桌面组件不适用根目录 MIT 许可证，也不接受通过公开 issue、PR、npm 包、日志或构建产物复制、修改、再分发或贡献桌面源码和资源。桌面端的内部发布流程、架构说明和验收记录保存在私有维护环境中；公开文档只描述与 CLI/SDK 兼容所需的接口边界。

如果应用需要支持桌面目标，请先通过维护者提供的内部流程获得宿主接入和发布授权。应用源码仍可使用公开的 SDK 和 CLI 构建 Web 包；桌面安装包、更新元数据和签名材料必须由内部发布流水线生成。
